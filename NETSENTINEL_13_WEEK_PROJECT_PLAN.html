Project Architecture & Execution Environment
Platform: NetSentinel (Shield NSM Platform) is a zero-dependency, pure Java network intrusion detection framework engineered on Java 21 LTS, Spring Boot 3, and Project Loom Virtual Threads.
Core Modules: Five decoupled components communicating via frozen JSON contracts: Module 1 Packet Dissection → Module 2 Deterministic Rule Engine → Module 3 Flow Anomaly Inference → Module 4 SQLite Storage Service → Module 5 Live SOC Web Dashboard.
Project Guide: Er. Ram Babu Buri (Assistant Professor, Department of Computer Science & IT).
